# Китай концепт 3

Адаптивная вёрстка V3 «Китай Go» из Figma от 27.10.2026: HTML, CSS и JavaScript без сборки и внешних библиотек. Все изображения, SVG и шрифты Onest сохранены локально.

## Запуск

`node server.mjs` → http://127.0.0.1:4175/. Для размещения достаточно статического хостинга; стартовый файл — `index.html`.

## Анимация и взаимодействие

- Первый экран появляется поэтапно. По исходной полосе маршрута проходит мягкий световой импульс: маска повторяет оригинальный SVG, поэтому свет остаётся внутри полосы.
- При прокрутке облака мягко поднимаются и сходятся, храм движется медленнее; за ними появляются следующие блоки. Прокрутка нативная. На мобильном амплитуда уменьшена.
- Блоки появляются снизу вверх один раз через IntersectionObserver. Вне первого экрана и в неактивной вкладке фоновая анимация приостанавливается.
- Ховеры предусмотрены для мыши; touch использует нажатие. Есть клавиатурный фокус, меню с Escape, диалоги с возвратом фокуса, раскрытие всех восьми карточек.
- На мобильном преимущества и туры листаются нативным свайпом со scroll-snap и точками: 4 преимущества, 4 тура, после раскрытия — 8 туров. Высота карточек согласована по содержимому. Hover на touch не применяется.
- `prefers-reduced-motion` отключает анимации и плавную прокрутку. Основное содержимое доступно без JavaScript.

## Дизайн и адаптация

Источник: [Figma V3, фрейм 50:1766](https://www.figma.com/design/r4hZA5vzybmLDXhocsvJhI/?node-id=50-1766). Сохранены структура, тексты, фотографии, логотип, палитра и графика V3. Для вложенных иллюстраций использован прямой экспорт фактических экземпляров: общий экспорт Figma терял переопределения вариантов.

В исходном файле нет мобильного макета. Мобильная композиция предложена при вёрстке с опорой на локальную V1: поля 20 px (320 px — 16 px), секции 64 px, точечная пагинация с активной вытянутой точкой, карточки выходят за край без внутренней белой полосы. Роли заголовков сохранены: H1 80 → 34–54 px, H2 60 → 30–42 px, названия направлений 40 → 28–30 px, подписи преимуществ 32 → 24–27 px, название тура 26 → 18–20 px, цена 32 → 25–27 px. Это предложенные размеры, а не существующие мобильные токены Figma.

Изображения туров, их названия, цены и длительность сохранены как в концепции, включая повторяющиеся карточки. Соответствие фотографий конкретным маршрутам и коммерческая актуальность условий не подтверждены. Новые фотографии не генерировались.

## Проверка и ограничения

Проверено в Chrome на ширинах 320, 360, 390, 768, 1024, 1440 и 1920 px: отсутствие горизонтального переполнения, рендер изображений, меню, Escape, диалоги, точки и раскрытие каталога. Проверен режим уменьшенного движения. Физические iPhone/Android и Safari не тестировались.

Телефон и контакты в макете демонстрационные. Подробные программы, реальные ссылки мессенджеров, отзывы и материалы блога не предоставлены. Эти действия открывают понятные пояснения. Страница не собирает заявки и не выполняет оплату; цены из макета не являются подтверждённым предложением. Включён `noindex,nofollow`.
